# 천해마루 스마트팜 · 관리

온실 운영 기록을 웹에서 입력하는 첫 사용 버전입니다. Cloudflare Pages에서 사용할 때는 D1에 저장하고, 화면에서 Excel 파일로 내려받을 수 있습니다.

## 클라우드 접속

- 주소: https://smart-farm-greenlog.pages.dev/
- 사용자 이름: `천해마루`
- 비밀번호: 이 PC의 `data/cloudflare-admin-password.txt` 파일. 이 파일과 실제 기록은 Git에서 제외합니다.
- Cloudflare Pages에서는 전용 로그인 화면에서 접속하며, 로그인 상태는 7일간 유지됩니다. 오른쪽 위에서 로그아웃할 수 있습니다. 이 PC의 `localhost` 화면은 서버가 보관한 로그인 정보로 같은 D1 데이터베이스에 연결합니다.
- 클라우드 관리 화면과 기록 API에 로그인이 필요합니다. 접속 주소는 공개되므로 비밀번호를 다른 사람에게 보내지 마세요.
- 클라우드에서 입력한 기록은 D1에 저장됩니다. 재배 기록 화면의 **엑셀 내려받기**로 현재 기록을 백업할 수 있습니다.
- `localhost`와 클라우드 주소에서 작성한 기록은 모두 같은 D1에 저장됩니다. 기존 `data/smart-farm.xlsx`는 이전 로컬 기록의 백업으로 남아 있으며 이후 자동 갱신되지 않습니다.

## 실행

1. 이 폴더에서 `npm install`을 한 번 실행합니다.
2. `npm run dev`를 실행합니다.
3. 브라우저에서 [http://localhost:4173](http://localhost:4173)을 엽니다.

실행 중인 터미널을 닫으면 로컬 웹 화면만 종료됩니다. 기록은 클라우드 D1에 남아 다른 기기에서 계속 볼 수 있습니다. 로컬 화면을 사용할 때도 인터넷 연결과 `data/cloudflare-admin-password.txt` 파일이 필요합니다.

## 이전 로컬 엑셀 기록

- 이전 기록 파일: `data/smart-farm.xlsx`. 현재 기본 실행 경로에서는 이 파일에 새 기록을 쓰지 않습니다.
- 개발·검증용으로 `SMART_FARM_DATA_FILE` 환경변수에 별도 엑셀 경로를 지정하면 로컬 엑셀 저장 모드로 실행됩니다.
- 씨앗 수량은 품종별로 관리하며, 파종 1판에 300립을 차감합니다.
- 사진에 적힌 육묘대 108홀·1차 정식대 40홀·2차 정식대 20홀은 별도 재배대 수용량 자료로 보관합니다. 파종판 300칸과 섞어 계산하지 않습니다.
- 이전 파일은 Excel에서 직접 열어 확인할 수 있습니다.
- 이 파일은 Git에서 제외되어 코드 변경이나 업데이트로 덮어쓰지 않습니다. 중요한 기록은 가끔 파일을 복사해 백업해 주세요.

## 현재 화면

- 대시보드: 날짜를 눌러 작업·메모를 등록하는 월간 달력, 오늘 할 일, 수확·판매·파기·파종 통계, 씨앗 부족과 미계량 알림
- 재배 기록: 품종 추가·미사용 품종 삭제, 씨앗, 파종, 수확·파기·판매, 작업 일정, 온습도·양액 투입일·pH·EC 측정, CO₂ 교체
- 재배실 배치도: 별도 3D 화면에 수직으로 쌓인 1층·2층, 각 층의 L1~L11·R1~R11 재배대. 층별 보기 가능
- 스마트팜 아카이브: 양액 비율과 필터 청소 자료를 보고, 새 자료를 추가·수정·삭제할 수 있습니다.
- 재배대 구조: 입구는 앞쪽 중앙 통로에 표시하고, 입구 왼쪽의 L10·L11을 각 층 6단으로 둡니다. 나머지 40개는 기본 5단입니다. 단수는 재배대별로 수정할 수 있으며, 재배 단계(1차·2차 육묘대 또는 정식대)는 아직 지정하지 않았습니다. 단계를 지정하면 해당 단계의 5단 또는 6단으로 맞춰집니다.
- 업무 일지: 날짜·제목·진행 내용을 남기고 수정·삭제할 수 있습니다. 클라우드에서는 D1에 저장하고 엑셀 내려받기에는 `업무일지` 시트가 포함됩니다.
- 재배 단계 기본 기간은 7일·14일·24일이며 수정할 수 있습니다. 재배대별 각 단의 자리 수는 확인 후 입력할 수 있습니다.

월간 일정에서 등록한 반복 작업은 완료가 늦어지면 지연 상태로 남습니다. 완료일을 기준으로 다음 일정이 자동 계산됩니다. 수확 무게는 나중에 입력할 수 있습니다.

정확한 베드 치수와 작물 배정, 육묘판 300칸 규격은 사용하면서 확인하고 수정합니다. 센서 자동 수집과 Google 스프레드시트 연결은 아직 포함하지 않았습니다.


## 온실 · 양액 현재값

대시보드에서 `temp_pv`, `humi_pv`, `ec_pv`, `ph_pv`를 10초마다 확인합니다. 온습도 SENSOR #1~4, 항온항습기(HVAC), 센서 4개 평균을 구분하며 EC와 pH는 양액기 값을 표시합니다. 평균은 네 센서 값이 모두 있을 때만 계산합니다. 측정 또는 수신 시각이 60초 이상 지나면 마지막 측정값으로 표시합니다. 연결 오류 중에는 마지막 값을 보존합니다.

로컬 실행은 기록을 D1에서 읽고 쓰면서 기존 수신기의 `http://127.0.0.1:8091/api/latest`를 서버에서 조회합니다. 필요 시 서버 환경변수 `SMART_FARM_SENSOR_URL`로 변경할 수 있습니다. 기존 수신기를 다시 시작할 필요는 없습니다.

Cloudflare Pages는 수신 PC의 localhost에 접근할 수 없습니다. 별도의 접근 제어된 수신 경로를 준비한 뒤 서버 환경변수 `SENSOR_UPSTREAM_URL`을 설정해야 온라인에서도 표시됩니다. 미설정 시 연결 대기로 표시합니다. 수신 경로는 위 `/api/latest`와 같은 JSON 형태를 반환해야 합니다. 브라우저에는 이 주소를 전달하지 않습니다. 이번 변경은 온라인 배포나 수신 PC의 외부 공개를 수행하지 않습니다.
