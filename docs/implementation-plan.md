# 첫 사용 버전 구현 순서

1. 웹 앱과 로컬 Excel 저장소를 만든다. 품종, 파종, 수확, 판매, 환경, 양액, CO₂, 일정, 베드 정보를 저장한다.
2. 대시보드에 월간 달력, 오늘 할 일, 통계, 계량 누락 및 씨앗 재고 알림을 연결한다.
3. 각 기록을 입력·조회하는 화면을 만든다. 300칸 기준 씨앗 차감과 반복 일정 계산을 적용한다.
4. 별도 온실 화면에 한 재배실의 1층·2층과 각 층 L1~L11·R1~R11 베드를 3D로 배치하고 품종을 지정할 수 있게 한다.
5. 실제 저장·재시작 후 기록 유지와 핵심 계산을 확인하고, 로컬 실행 방법을 남긴다.

첫 버전은 사용자가 직접 입력하는 방식으로 운영하며, 실제 사용 후 화면과 계산 규칙을 수정한다.
