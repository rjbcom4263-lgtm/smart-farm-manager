# 스마트팜 관리 웹 프로그램 설계서

## 목적

온실의 작물 재배와 작업을 웹에서 기록하고, 메인 화면에서 이번 달 일정과 주요 수치를 빠르게 확인한다. 종이 기록에서 놓치기 쉬운 수확 계량, 파기량, 파종량, 양액 투입, CO₂ 통 교체 이력을 차례로 관리한다. 실제 사용 후 현장 피드백을 반영해 기능을 수정할 수 있는 첫 버전을 목표로 한다.

## 사용자와 사용 환경

- 온실 운영자가 웹 브라우저에서 직접 입력하고 확인한다.
- 제공된 배치표의 한 재배실 1층·2층, 각 층의 L1~L11·R1~R11 베드 번호를 기본 구조로 사용한다. 정확한 치수와 읽기 어려운 손글씨 표기는 사용 중 확인해 수정한다.
- 재배대 종류는 1차 육묘대(6단), 2차 육묘대(6단), 3차 정식대(5단)이다. 사진에서 번호별 종류를 확정할 수 없어 초기값은 미지정으로 두고 각 재배대에서 지정한다.
- 첫 사용 버전은 로컬 Excel 파일에 기록한다. Google 스프레드시트 연결은 사용 피드백을 본 뒤 결정한다.
- 온실 센서나 설비에 직접 연결하는 것은 첫 버전 범위에 포함하지 않는다. 온도·습도는 우선 날짜별 기록으로 관리한다.

## 화면 구성

### 대시보드

- 메인 화면은 온실 3D 배치도보다 일정과 통계를 우선한다.
- 월간 달력과 오늘 할 일 목록을 별도 영역으로 표시한다.
- 월간 요약에는 수확, 판매, 파기, 파종 수량과 씨앗 재고 알림 등 운영에 필요한 항목을 둔다.
- 오늘의 온도·습도 기록과 최근 기록 시각을 보여준다.
- 계량이 빠진 수확 기록과 씨앗 부족 또는 재고 기준 이하 알림을 눈에 띄게 표시한다.

### 온실 배치도

- 별도 메뉴에서 온실의 3D 배치도를 제공한다.
- 구역이나 베드를 선택하면 해당 위치의 작물과 재배 정보를 확인할 수 있도록 설계한다.
- 첫 버전에는 한 재배실의 1층·2층과 각 층의 L1~L11·R1~R11을 배치한다. 사진의 표는 이 번호 체계를 알려주지만 정확한 실측 치수는 제공하지 않으므로 3D 형태는 도식적으로 표현한다.
- 별도 수량 계산지의 육묘대 108홀·1차 정식대 40홀·2차 정식대 20홀은 재배대 수용량 참고값이다. 씨앗 재고 계산에 쓰는 육묘판 300칸과 구분한다.
- 화면 예시 이미지의 세부 설비나 자동화 동작은 요구사항으로 간주하지 않는다.

### 기록 메뉴

- 작물·품종 관리
- 파종 및 씨앗 재고
- 수확·파기 및 판매
- 온도·습도 기록
- 작업 일정
- 양액 투입일
- CO₂ 통 교체 이력

## 기능과 업무 규칙

### 품종과 파종

- 품종은 사용자가 추가할 수 있다.
- 첫 등록 품종: 프릴아이스, 이자벨, 로메인, 버터헤드, 알사시아, 오비레드.
- 육묘판 규격은 한 종류로 시작하며, 한 판은 300칸으로 계산한다.
- 파종 기록에는 날짜, 품종, 육묘판 수를 입력한다.
- 파종 씨앗 수는 `육묘판 수 × 300립`으로 계산해 해당 품종의 재고에서 차감한다.
- 씨앗 재고는 낱개 수량(립)으로 관리한다. 최초 재고를 입력할 수 있고, 구매 수량을 더하며, 파종 시 자동 차감한다. 운영자가 재고를 직접 조정할 수 있다.
- 월간 일정에 품종별 예정 육묘판 수를 입력하면 필요한 씨앗 수와 현재 재고를 비교해 부족 수량을 표시한다.
- 품종별 재고가 1,000립 이하이면 알림을 표시한다. 예정 파종량보다 재고가 적은 경우에는 부족량도 함께 표시한다.

### 수확·파기·판매

- 수확 기록에는 날짜, 구역·베드, 품종, 상자 수와 실제 무게를 기록한다. 상자 수와 실제 무게는 별도 값으로 보관하며, 상자당 무게로 환산하지 않는다.
- 파기량은 수확 기록과 함께 상자 수 및 무게로 따로 기록한다.
- 무게를 아직 재지 않았어도 수확 기록을 저장할 수 있다. 무게가 없는 기록은 빨간색으로 표시해 계량이 필요한 상태임을 알린다.
- 판매일은 사용자가 직접 입력한다. 판매량 입력 방식은 우선 간단하게 제공하고 사용 피드백으로 조정한다.

### 반복 작업과 달력

- 사용자는 월간 달력에서 첫 작업일과 반복 간격(며칠마다)을 등록한다.
- 일정은 반복 간격에 따라 달력에 표시한다. 오늘 할 일 목록은 오늘 예정된 작업을 보여준다.
- 작업이 예정일에 완료되지 않으면 미완료·지연 상태로 남아 오늘 할 일 목록에서 계속 확인할 수 있다.
- 작업을 완료하면 다음 반복일은 완료일에서 설정한 간격만큼 뒤로 계산한다. 예: 7일 간격 작업을 10월 1일에 완료하면 다음 일정은 10월 8일이다.

### 환경·투입 기록

- 온도와 습도는 날짜별로 입력하고 기록을 조회할 수 있다. 첫 버전에서 센서 자동 수집은 하지 않는다.
- 양액은 온실 전체 투입으로 간주하며, 우선 투입 날짜만 기록한다.

### CO₂ 통 순환

- CO₂ 통은 5개를 순환 사용한다: 1→2→3→4→5→1.
- 통을 교체할 때 교체 날짜와 통 번호를 기록한다.
- 다음 통 번호를 순환 순서에 맞춰 기본 선택한다. 사용자가 필요한 경우 수정할 수 있다.
- 기록이 쌓이면 통별 교체 간격과 다음 교체 예정일을 추정해 표시한다. 추정치는 기록에 근거한 참고 정보로 제공한다.

## 데이터 구조 개요

- 품종: 이름, 사용 여부, 씨앗 재고(립)
- 파종: 날짜, 품종, 육묘판 수, 계산된 파종 립 수
- 작업 일정: 작업 이름, 첫 예정일, 반복 일수, 현재 예정일, 완료 상태와 완료일
- 수확: 날짜, 위치, 품종, 수확 상자 수·무게, 파기 상자 수·무게, 계량 상태
- 판매: 판매일과 판매 수량
- 환경 기록: 날짜, 온도, 습도
- 양액: 전체 온실 투입일
- CO₂ 교체: 교체일, 통 번호

## 첫 버전에서 다루지 않는 항목

- 센서 자동 수집과 온실 장비 원격 제어
- 정확한 실측 치수를 반영한 3D 모델과 자동화 설비 시뮬레이션
- 사용자 계정·권한 체계
- 씨앗 발아율이나 폐기율을 반영한 구매량 예측
- 판매량과 수확량을 자동으로 연결하는 회계·정산 기능

## 사용 중 확인할 항목

- 판매 기록의 상세 수량 단위와 화면 입력 방식.
- 실제 온실 베드의 작물 배정과 3D 배치의 치수·형태.
- 육묘판 300칸이 맞는지 현장에서 한 번 더 확인한다.
